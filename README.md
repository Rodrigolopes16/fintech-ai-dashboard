# 📈 Fintech AI Dashboard — SaaS Financeiro Dinâmico

Um dashboard financeiro interativo desenvolvido com **Next.js 15 (App Router)**, **TypeScript**, **Tailwind CSS** e integração com **Inteligência Artificial (Google Gemini)** para análise preditiva de fluxo de caixa.

![Fintech AI Dashboard](public/preview.png)

## 🚀 Funcionalidades

- **Métricas Financeiras em Tempo Real:** Cálculo dinâmico de Saldo Total, Receitas Acumuladas e Despesas Acumuladas.
- **Gestão de Transações:** Adição dinâmica de novas entradas e saídas de caixa via modal com atualização instantânea de estado.
- **Gráficos Interativos:** Visualização de desempenho financeiro mensal desenvolvida com Recharts.
- **Análise Preditiva de IA:** API Route backend que processa as métricas do usuário e retorna análises preditivas personalizadas sobre a saúde financeira.
- **Design Moderno:** Interface escura (Dark Mode) responsiva construída com Tailwind CSS e Lucide Icons.

## 🛠️ Tecnologias Utilizadas

- **Framework:** Next.js (App Router)
- **Linguagem:** TypeScript
- **Estilização:** Tailwind CSS
- **Componentes de Gráficos:** Recharts
- **Ícones:** Lucide React
- **IA & Backend:** Next.js API Routes / Google Gen AI API
